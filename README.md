PORTAFOLIO WEB PERSONAL — Proyecto Scrum

Este proyecto consiste en el desarrollo de un portafolio web profesional utilizando Next.js, React, TypeScript y Tailwind CSS, siguiendo el marco de trabajo Scrum, con Sprint Backlog, historias de usuario, definición de done, branching profesional, Pull Requests y control de versiones con Git y GitHub.

Tecnologías Utilizadas

Next.js 14
React 18
TypeScript
Tailwind CSS
Node.js
Git & GitHub
Scrum como metodología ágil

Instalación del Proyecto
Sigue estos pasos para instalar y ejecutar el proyecto:

1️⃣ Clonar el repositorio
git clone https://github.com/ManuelFreddyjota/practica2-portfolio-scrum

2️⃣ Instalar dependencias
npm install

3️⃣ Ejecutar el servidor de desarrollo
npm run dev

Luego abre:
http://localhost:3000

Estrategia de Branching

Ramas principales:

master → Versión estable

develop → Integración de funcionalidades

Ramas secundarias:

feature/hero
feature/about-me-portfolio

🧾 Convenciones de Commits

Este proyecto usa Conventional Commits:
feat: nueva funcionalidad
fix: corrección de errores
style: cambios visuales
docs: documentación
refactor: cambios internos
chore: mantenimiento
